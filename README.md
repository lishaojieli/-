# 协作间 · Codex 与 DeepSeek

运行在本机的智能体协作聊天室。你在群里发布任务、补充要求，Codex 执行，DeepSeek 分析和审阅，网页实时显示公开回复与任务状态。

## 功能

- 独立聊天对应独立任务，保留记录、草稿、暂停状态及工作目录。
- 支持全体协作、Codex 和 DeepSeek、单个成员，以及点名交流。
- 固定 1–3 轮，或“自动推进至完成”：讨论、执行、验证和修复，验收通过后结束。
- 调度层管理验收、两层安全预算、进展去重、检查点与动作执行记录。
- 连续两轮无实质进展、预算耗尽、必要输入或权限缺失时暂停，由用户明确继续。
- 展示 Codex 的 5 小时与周剩余用量、重置时间，以及 DeepSeek 余额。
- 两个浏览器窗口通过 SSE 同步；桌面和手机宽度均可使用。

## 本机运行

完整连接配置及密钥保存功能面向 Windows，需要 Node.js 22 或更高版本。

1. 克隆本仓库，进入目录。
2. 双击 `start-room.cmd`，或在终端运行 `npm start`。
3. 打开 <http://127.0.0.1:4317/>，点击“连接设置”。
4. 确认已安装且登录的 Codex 程序路径、工作目录，填写自己的 DeepSeek API Key。

项目使用 Node 内置模块，没有额外运行依赖。Windows 启动器也可使用 Codex 配套的 Node 运行环境。

连接测试会向 DeepSeek 发送简短问候，可能产生接口费用。余额查询本身不调用聊天模型。

## 数据与凭据

首次运行自动创建 `data/` 和 `workspace/`。聊天与权威调度状态保存在 `data/room.json`，连接密钥通过当前 Windows 用户的凭据保护加密保存。密钥不进入公开消息或浏览器存储。

`data/`、`workspace/`、环境文件、加密配置、日志及临时文件均已加入忽略规则。本仓库只包含应用源码、测试、启动脚本和文档，不包含任何已使用账号的凭据与聊天记录。每位使用者需自行配置连接。

服务只监听本机回环地址；关闭网页不会停止本机服务。Windows 下可运行 `stop.ps1` 停止服务。

## 自动推进与验证

默认单次运行最多 **30 轮／30 分钟有效时间**，同一聊天累计最多 **100 轮／120 分钟**。继续只重置单次预算，累计额度需用户显式增加。只有调度层能写入完成状态；成员自述、网址或旧版本检查不能替代验收。

中断动作可能已产生副作用，不确定结果需核对后再继续。没有可靠计时的旧版本聊天会要求恢复累计用时，不默认归零。自动客观检查目前支持文件内容、Node 语法及 Node 测试；主观要求由另一位成员审阅。

运行测试：

```sh
npm test
```

当前验证记录为 62 项测试通过。调度场景使用假成员、假工具经过真实服务入口，不调用付费模型；还覆盖真实本机检查和子进程强制退出恢复。真实模型对结构化记录的遵从性未在这些测试中验证，不合格记录会触发明确暂停。

详细使用方法见 [使用说明](使用说明.md)，修改文件、验证场景和已知边界见 [自动推进验证说明](自动推进验证说明.md)。
